## CRITICAL PRIORITY

### IRQControl (Bitsum)
- URL: https://bitsum.com/parkcontrol/
- IRQControl may be bundled with Process Lasso Pro or available standalone
- Alternatively: check if latest Process Lasso includes IRQControl functionality
- Save to: E:\YAZX_GitHub\tools\IRQControl\
- Purpose: Manage Interrupt Affinity (which CPU core handles which device interrupt)
- Note: MSI Mode only enables message-signaled interrupts; IRQControl sets CPU AFFINITY for those interrupts

### DDU (Display Driver Uninstaller)
- URL: https://www.wagnardsoft.com/display-driver-uninstaller-ddu-
- Download: DDU vXX.X.X.X.exe (latest stable)
- Save to: E:\YAZX_GitHub\tools\DDU\
- Purpose: Clean GPU driver removal before fresh install
- Note: Run in Safe Mode for best results (or Normal Mode Disconnect + Disable WU option)
